# FlyOne redesign study

Two responsive landing-page studies for the same public aviation brand, built to compare different visual directions without presenting either version as commissioned client work.

- [Version 1 — kinetic direction](https://forblune.github.io/flyone-landing/)
- [Version 2 — cinematic direction](https://forblune.github.io/flyone-landing/v2/)

## What to look for

Version 1 uses large type, faster pacing, and a compact mobile navigation. Version 2 slows the page down with a restrained palette, editorial spacing, and a more narrative project sequence.

Both versions include:

- responsive layouts for desktop, tablet, and mobile
- keyboard-visible navigation and reduced-motion support
- clear section landmarks and descriptive image text
- static HTML, CSS, and JavaScript with no build step

## Project boundary

This is a self-initiated, non-commissioned redesign study based only on information and images already available on the public FlyOne website. It is not affiliated with, endorsed by, or delivered to FlyOne. No private material, customer data, performance claim, or client testimonial is included.

## Run locally

Open `index.html` for Version 1 and `v2/index.html` for Version 2. A small local server is recommended when checking both versions:

```sh
python -m http.server 8080
```

Then visit `http://localhost:8080/` and `http://localhost:8080/v2/`.
